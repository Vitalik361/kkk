# Backtest Logger

Manual backtesting research terminal for SPY Levels + Net Drift + ES Absorption.

## Philosophy
SPY Levels are entered manually by the trader. The app does not assume a single data provider and does not require live market data.

## Run
npm install
npm run dev

Open http://localhost:3000

Data is stored in browser localStorage in this MVP. Export CSV for durable analysis. A cloud database and Notion sync can be added after the schema is finalized.
